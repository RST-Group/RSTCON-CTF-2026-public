# Eight Valves  -  Solution

## Identify the language

`valves.bf` contains only the characters `+ - . > < [ ] ,`. That is Brainfuck,
an esoteric language with eight instructions operating on a byte tape and a data
pointer. The `.bf` extension and the all-symbol body give it away.

## Run it
Run it
```
beef valves.bf
# or
bf valves.bf
```
Or paste it into any online Brainfuck interpreter.

`rstcon{eight_valves_run_the_tape}`
