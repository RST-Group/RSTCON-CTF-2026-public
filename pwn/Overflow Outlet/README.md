# Overflow Outlet

**Category:** Binary Exploitation  
**Author:** f8al

## Description

Some hydro skid left its valve controller hanging off the network. It's sitting
there waiting for an "actuator sequence," and the valve stays shut until the
internal gate flips to the value it's after.

Provided: outlet (the binary).

Mirror 1: `nc 18.215.143.250 9001`\
Mirror 2: `nc 18.145.136.91 9001`

## Flag

```
rstcon{st4ck_sm4sh_opens_the_v4lve}
```
